# T05 – D3 Multi-chart Webpage (TV power consumption)
Scatter plot, line chart, bar chart and donut chart, each in its own JS file (`js/`), all responsive via SVG `viewBox`.

Data (all in `data/`, from the Ex5 pack):
- `Ex5_TV_energy.csv` – scatter (star2 vs energy_consumpt) and donut (sum of `count` per screen_tech)
- `Ex5_ARE_Spot_Prices.csv` – line chart (state prices + average)
- `Ex5_TV_energy_Allsizes_byScreenType.csv` and `Ex5_TV_energy_55inchtv_byScreenType.csv` – bar chart (toggle)

"LCD (LED)" in the TV file is shown as "LED" so labels and colours match the other files.
Column names live in `js/config.js`. Run with Live Server (VS Code) so the CSV files load.

AI use: code drafted with AI assistance and reviewed by the author.
